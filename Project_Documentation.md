# Student Performance Analytics System

## 1. Project Title
Student Performance Analytics System

## 2. Objective
The objective of this project is to analyze student marks using Python,Pandas, and NumPy. It calculates student performance and displays useful academic information.

## 3. Technologies Used 
- Python
- Pandas
- NumPy
- CSV datset
- Visual Studio code

## 4. Dataset Description
The project uses a CSV file named students.csv containing student names and subject marks. The datset is processed using Pandas.

## 5. Implementatoin
1. Read student records from the CSV file using Pandas.
2. Calculate total marks for each student.
3. Calculate average marks for each student.
4. Assign grades based on the defined grading rule.
5. Identify pass and fail results.
6. Find the top three performers.
7. Calculate subject-wise average marks using NumPy.
8. Search for students by name.

## 6. Key Features
- Student marks analysis
- Total and average calculations
- Grade assignment
- Pass/fail identification
- Top three performers
- Subject-wise average analysis
- Student search

## 7. Output
The program displays student performance information including totals, averages, grades, pass/fail results, top performers, and subject-wise averages.

## 8. Final Outcome
The project successfully demonstrates how Python, Pandas, and NumPy can be used to analyze student performance.

## 9. Challenges and Learning
During development, I learned how to install Python libraries, read CSV files, process student data, calculate averages using NumPy, fix errors, and upload project files to GitHub.
