# Student Performance Analytics System

## Project Description
The Student Performance Analytics System is a Python-based project that analyzes student marks and displays useful academic information.

## Technologies Used
- Python
- Pandas
- NumPy
- CSV

## Features
- Reads student records from a CSV file.
- Calculates total and average marks.
- Assigns grades to students.
- Identifies pass and fail results.
- Displays the top 3 performers.
- Calculates subject-wise average marks.
- Searches for students by name.
- Displays pass percentage.

## Project Files
- main.py - Contains the Python program.
- students.csv - Contains student names and marks.
- README.md - Contains project documentation.

## How to Run
1. Install Python.
2. Install the required libraries using `python -m pip install pandas numpy`.
3. Open the project folder in VS Code.
4. Run `python main.py` in the terminal.

## Conclusion
This project demonstrates how Python, Pandas, and NumPy can be used to analyze student performance.
